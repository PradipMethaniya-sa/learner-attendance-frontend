# Learner Attendance Frontend

This repository contains the frontend application for managing learner attendance in educational institutions.  
The application provides a secure, scalable, and user-friendly interface for managing schools, learners, and attendance records.

## Overview

The Learner Attendance Frontend supports administrative and academic workflows such as:
- School management
- Learner management
- Attendance tracking
- Secure authentication and role-based access

The application integrates with backend APIs to fetch and manage data in real time.

## Features

- Secure authentication using JWT
- Role-based access control
- School list and add/edit school management
- Learner attendance tracking
- Reusable UI components
- Data tables with pagination, sorting, and filtering
- Centralized HTTP interceptor and global error handling
- Confirmation dialogs for critical user actions
- Responsive and modern UI design

## Tech Stack

- Angular
- TypeScript
- Tailwind CSS
- RxJS
- RESTful APIs

## Prerequisites

Make sure the following are installed on your system:

- Node.js (v20 or later)
- Angular CLI
